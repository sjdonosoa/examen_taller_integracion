# Parte 1 · Selección múltiple

Dos pruebas de 18 preguntas con el mismo reparto que el examen 2026-01 (6 Ingeniería de Software, 7 Gestión de Proyectos TI, 5 Gestión de Operaciones TI), incluyendo preguntas de **cálculo** (EVM, PERT, reservas, disponibilidad, NPS) y de **análisis de código Python**.

```bash
python quiz.py 1             # rendir la prueba 1 (30 minutos, sin apuntes, con calculadora)
python quiz.py 2 --mezclar   # preguntas y alternativas en orden aleatorio
python quiz.py 1 --pauta     # ver todas las respuestas con su explicación
```

Al final ves tu nota, el desglose por ramo y la explicación de cada pregunta que fallaste. Las preguntas están en `prueba_1.json` y `prueba_2.json`: si quieres agregar más, sigue el mismo formato.
